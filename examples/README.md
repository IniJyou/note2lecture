# N0 原创样例

这三篇笔记及 `assets/` 下两幅示意图为 Note2Lecture 新写、新绘的公开演示材料，没有引用私人笔记、电子书节选、真实训练数据或第三方图片。允许将这些样例和图片公开展示、复制、修改并随项目分发；本说明仅覆盖本目录材料，不替其他项目文件设定许可。

数学概念属于常见基础知识，叙述、数值、代码示意和配图为本轮专门编写。文中的数值结论可手算核对，代码用于排版与内容保真检查，导出过程中不运行。

| 文件 | 内容 | 主要覆盖 |
| --- | --- | --- |
| [01-mean.md](01-mean.md) | 从三个数理解算术平均 | 元数据、三级标题、强调、两层列表、脚注、链接、代码、PNG |
| [02-projection.md](02-projection.md) | 一维正交投影的最小距离性质 | 定义、引理、定理、证明、例题、向量形状、公式和前向引用 |
| [03-online-mean.md](03-online-mean.md) | 逐项更新平均值 | 多行公式、基础表格、JPEG、中文空格路径、长代码行与分页观察 |

语法按 [N0.1 输入规范](../docs/input-spec.md) 编写；它是 N1 计划支持的约定，当前没有转换器。具体编号、内容锚点和边界变体验收见 [期望输出](../docs/expected-output.md)。三篇均为正常输入，故障通过后续复制到临时目录并做单项修改构造，避免把破损样例当成功样例。

| 资源 | 原创绘制内容 | 规格与用途 |
| --- | --- | --- |
| `assets/mean-flow.png` | 输入三个数、求和、除以数量的流程 | 1200 × 320，RGB PNG，白底，样例 01 引用 |
| `assets/批次 示意.jpg` | 序列 2、4、8、10 分为两批的示意 | 1200 × 360，RGB JPEG，白底，样例 03 引用 |

图片内部使用简短数字和英文标记，中文说明在 Markdown 图题中；黑白打印不依赖颜色区分。它们是静态教学示意，不是代码执行或模型实验结果。

本目录没有预生成的 PDF、LaTeX 或“黄金页面”。N1 对固定输入完成首次编译、内容核对和逐页检查后，才能建立实际输出基线。
