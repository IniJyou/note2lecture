# 原创样例

本目录五篇笔记及 `assets/` 下两幅示意图为 Note2Lecture 新写、新绘的公开演示材料，没有引用私人笔记、电子书节选、真实训练数据或第三方图片。允许将这些样例和图片公开展示、复制、修改并随项目分发；本说明仅覆盖本目录材料，不替其他项目文件设定许可。前三篇来自 N0；第四篇是 N2 补充的功能样例；第五篇为 v0.1.0 候选版新写的首次体验样例。

数学概念属于常见基础知识，叙述、数值、代码示意和配图为本轮专门编写。文中的数值结论可手算核对，代码用于排版与内容保真检查，导出过程中不运行。

| 文件 | 内容 | 主要覆盖 |
| --- | --- | --- |
| [01-mean.md](01-mean.md) | 从三个数理解算术平均 | 元数据、三级标题、强调、两层列表、脚注、链接、代码、PNG |
| [02-projection.md](02-projection.md) | 一维正交投影的最小距离性质 | 定义、引理、定理、证明、例题、向量形状、公式和前向引用 |
| [03-online-mean.md](03-online-mean.md) | 逐项更新平均值 | 多行公式、基础表格、JPEG、中文空格路径、长代码行与分页观察 |
| [04-obsidian.md](04-obsidian.md) | 用 Obsidian 记一次均值计算 | 双链、别名、同篇跳转、图片嵌入、note/tip/warning 提示框及代码字面量；使用 obsidian 模式 |
| [05-first-lecture.md](05-first-lecture.md) | 从笔记到讲义：一次计算复核 | 普通 Markdown、均值与平方距离公式、表格、已有原创 PNG、JSON 与 PowerShell 代码；使用 markdown 模式 |

前三篇按 [N0.1 输入规范](../docs/input-spec.md) 编写，已由 N1 完成转换与固定样例验收；具体编号、内容锚点和边界变体验收见 [期望输出](../docs/expected-output.md)。第四篇由 N2 的显式 obsidian 模式转换，支持规则和检查结果见 [Obsidian 功能样例说明](../docs/obsidian-fixture.md)。故障通过复制到临时目录并做单项修改构造，避免把破损样例当成功样例。

图片内部使用简短数字和英文标记，中文说明在 Markdown 图题中；黑白打印不依赖颜色区分。它们是静态教学示意，不是代码执行或模型实验结果。

本目录保存原稿与资源。四篇的当前公开 PDF、LaTeX 源包和预览图见 [效果对照](../docs/demo.md)，生成及复现说明见 [N5 记录](../docs/n5-validation.md)。历史定稿产物与工程检查仍保留在本机 Git 忽略目录；用户于 2026-10-25 对提示框样张给出正面反馈，当前样式先沿用。
