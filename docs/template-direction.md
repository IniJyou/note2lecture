# 首套中文讲义模板方向

名称：**清简讲义 v0.1**。2026-10-23 用户已确认首套字体、正文密度与数学环境风格，三篇定稿样张检查通过，见 [验收记录](n1-validation.md)。下表记录当前规格，实际模板以 `templates/lecture/` 为准。

## 1. 阅读与打印方向

单栏 A4，白底黑字，装饰克制。按普通技术讲义设计：标题、目录、正文连续排版，不为短笔记单独留一张封面。颜色不承担语义，黑白打印也能分辨标题、环境和代码。

| 部位 | 首轮参数与方向 | 页面核对重点 |
| --- | --- | --- |
| 页面 | 上下边距约 24 mm、左右约 25 mm；正文宽约 160 mm | 无贴边、裁切；图表与公式均在版心内 |
| 正文 | 约 11 pt，行距参数 1.4，段首缩进 2 汉字（用户已确认） | 中英混排与公式不挤压；列表不叠加正文缩进 |
| 标题区 | 文档标题约 22 pt，作者/日期约 10 pt；日期仅在输入给定时显示 | 标题不重复；长标题可自然折行 |
| 章节 | 一级约 16 pt、二级约 13 pt、三级约 11 pt 加粗；编号自动生成 | 不在页底留下孤立标题；标题后至少容纳两行正文 |
| 目录 | 标题区之后，列到第二级，页码和链接有效；允许同页衔接正文 | 环境标题不进入目录；三级标题仍可在正文编号 |
| 页眉页脚 | 页眉为简短文档名，页脚居中页码，正文页从 1 连续编号 | 标题首页可不设页眉；长文档名不越界 |
| 数学 | 行内公式贴合正文；独立公式居中，编号在右；多行按等号对齐 | 编号不挤压公式，不自动删项或改写推导 |
| 定义与例 | 中文粗体题头，正文正体，依靠间距区分 | 不用大片深底色，不整块缩小 |
| 定理与引理 | 中文粗体题头，正文正体，无框无线（用户已确认） | 长块可自然断页；题头不与首段分离 |
| 证明 | “证明”起始，结束方块靠右，正文正体 | 两个证明各一个结束标记，跨页不丢结束内容 |
| 代码 | 等宽约 9 pt、浅灰底或细边线，无自动行号；可视觉折行 | 中文注释有字形；长行不裁切，源内容不改；不使用需外部执行的高亮方案 |
| 表格 | 约 10 pt，简洁横线，数字按列对齐，题注在上 | 行列不混；跨页时表头重复，无裁切；超宽时报告 |
| 图片 | 居中、等比适配，图题在下约 9.5 pt | JPEG 不模糊到无法阅读；图与题注同页，无拉伸 |
| 脚注 | 约 9 pt，上标编号；保持与正文的清楚分隔 | 不漏尾句、不压到页脚 |

第一套只做这一种风格。字号、间距与分页已结合实际页面检查；不扩展多主题、皮肤或模板商城。

## 2. 字体方向与依赖边界

N0 候选组合为思源宋体/黑体。N1 实际采用本机 TeX Live 已有的 **Fandol 宋体/黑体/仿宋 + Latin Modern 正文/数学/等宽字体**，无需新装字体，中文代码注释已有字形。思源字体未安装或验收，不能把当前样张称为思源样张。

N1 先检查 Windows 实际字体与 TeX 可用字体，再固定精确字体名称、版本标识和配置；缺字体明确报告，由用户执行安装。可先用已具备的完整字体组做最小验证，并在样张记录差异，不能静默替换字体后把版式当成同一结果。模板不随包分发未经核对的字体文件。

2026-10-23 用户已确认 11 pt、`setstretch=1.4`，数学环境保留教材式无框；正式模板已更新行距，数学环境样式不变。西文与数字按用户要求试排 **Times New Roman 7.12**，公式搭配 **TeX Gyre Termes Math 1.543**。本机 Times New Roman 的常规、粗体、斜体和粗斜体四个字体均已具备，但均无 OpenType `MATH` 表，故公式使用本机已有的配套数学字体，不将普通西文字体直接当作数学字体。

试排位于 `output/style-review/times-new-roman/`：`font-comparison.pdf` 两页依次为原 Latin Modern 组合与 Times 组合，均为 11 pt、1.4 行距；另有样例 02、03 的实际试排 PDF，分别为 2、3 页。中文仍为 Fandol，代码仍为 Latin Modern Mono，试排中显式固定代码字体缩放，避免正文换字体连带放大代码。已实际查看全部 7 页，核对正文源、编号引用、资源与代码文件；结果及字体摘要见同目录 `review-checks.json`。未下载、安装或分发字体文件。

**最终选择：用户在对照后选择 A，保留 Latin Modern 组合。** 西文正文为 Latin Modern Roman，公式为 Latin Modern Math，等宽代码为 Latin Modern Mono；中文保留 Fandol。Times 组合仅作历史对照，未加入转换器默认配置或依赖。按该组合与 1.4 行距重新导出的三篇 PDF 和源包位于 `output/n1-approved/`，分别为 2、2、3 页；已核对内容与编号、迁移源包重编译并实际查看全部 7 页。用户确认的是样张中的风格选择，重新导出版本的逐页检查由助手完成；固定结果已记录 `style_approved=true`，不代表后续任意输入自动通过验收。

## 3. 样张内容安排

| 观察组 | 输入与预期画面 | 确认事项 |
| --- | --- | --- |
| A：基础阅读 | 样例 01；紧凑标题区、两级目录、正文、脚注、流程图和代码 | 留白、正文密度、中英文与代码字体是否舒适 |
| B：数学讲义 | 样例 02；五种数学结构、带编号/无编号公式、前向引用 | 环境区别是否清楚，中文名与计数是否正确，证明是否连贯 |
| C：长内容 | 样例 03；多行公式、五列表格、中文空格路径图片和长代码行 | 折行、图题表题、列宽、页底与页顶衔接是否自然 |
| D：分页边界 | 仅在样张工作副本中缩短可用高度或增加边界内容 | 标题孤行、长环境断页、过大空白、代码/表格跨页是否可接受 |

样张不预先指定“必须四页”等页数。N1 生成后记录实际页数、每页截图、问题位置与修复结果，并使用 PDF 检查 skill 实际查看所有页面。页面检查包含内容是否完整、字符是否缺失、是否越界，不能仅看编译日志。

用户已完成本套样张的字体、正文密度和环境强调选择。助手完成定稿导出的内容核对与逐页检查；审美确认不替代公式、编号或资源检查。后续输入仍需按文档实际复核。
