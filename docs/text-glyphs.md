# 正文特殊字符与缺字诊断

2026-10-27。适用于 `markdown` / `obsidian`；默认 `strict` 的字体规则不变。

## 字体与显示规则

中文仍使用 Fandol，普通西文、数学和代码仍使用 Latin Modern。仅对已识别的正文字符切换字体，不把正文自动改写为公式，不改原稿。

| 内容 | 排版规则 |
| --- | --- |
| 正文直接输入的希腊字母，如 `λ`、`α`、`Ω` | FreeSerif，保留所在文字的粗体/斜体样式；识别希腊字母区中的字母并继续检查实际缺字，不保证任意组合重音序列 |
| `✓`、`⚠`、`❌` | FreeSerif 中的同符号黑白字形 |
| `💡` | Windows 已有的 Segoe UI Symbol，显示为黑白灯泡 |
| 上述四个符号后紧接的 `U+FE0E` / `U+FE0F` | 保留在 TeX 原参数中，排版副本采用黑白字形，因此 PDF 复制文本可不含样式选择符 |
| 其他 Emoji、孤立选择符及未覆盖字符 | 不自动删除或替换；编译缺字仍报告错误 |

应用位置包括正文、基础样式、列表、表格、脚注、链接显示文字和标题。链接地址保持原样。H1 书名经受控通道处理；显式 YAML 的书名与作者仍作为字面文本，不因字形回退启用 Markdown 或 TeX 指令。目录、页眉和 PDF 书签保留文字内容。

数学节点、行内代码和代码文件不走正文替换通道，原文及保护检查保持；本轮不承诺代码中的任意 Emoji 能显示，也不扩展数学命令白名单。其他缺字继续诊断。

普通模板增加 TeX Live 的 `FreeSerif.otf`、`FreeSerifBold.otf`、`FreeSerifItalic.otf`、`FreeSerifBoldItalic.otf`。含灯泡时还检查 `seguisym.ttf`；若缺少，报告 `DEPENDENCY_MISSING`，不安装、不改用另一图案。字体不随源包分发，实际摘要进入 manifest；迁移含灯泡的源包需要目标 Windows 已有 Segoe UI Symbol。`doctor` 检查基础依赖，普通模式的这些额外字体在实际导出时检查。

manifest 记录 `text_glyph_fallback`、原字符序列及数量、字体和黑白样式选择。中间 Markdown 表格使用明确竖线划分列，防止 Unicode 显示宽度使空格分列截断受控宏；不更改表格的单元格内容与次序。

## 缺字诊断

`compile: true` 只表示生成 PDF；有 `GLYPH_MISSING` 时仍为 `status: failed`，不能当作验收通过。

同一个字符的重复日志汇总为一项，hint 记录日志次数，`related` 列出原稿中的字符候选位置。只有一处源字符时可给出确定位置；有多处或找不到时标为近似。候选列表不是逐个认定的错误点，标题与页眉也可能重复使用同一源字符。缺字日志没有 TeX 行号时，不再借用附近溢出日志的行号定位。
