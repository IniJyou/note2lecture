# 常见笔记兼容规则

更新：2026-10-26。适用于 `--profile markdown` / `obsidian`；strict 的原规则保持。原笔记只读，模型与代码执行关闭。

## 公式宽度

A4 正文宽 160 mm；列表等容器使用缩进后的实际 `linewidth`。测宽约束最终排版，不要求原公式天然小于 160 mm。

普通无编号独立公式能放下时保持原样。超宽时依次尝试后续外层关系符、首个外层关系符，以及明确的外层二元加减号；加减片段按可用宽度合并，避免每项独占一行。优先选无需缩放的方案；安全方案仍略宽时，才使用现有 1.12 倍边界内的小幅缩放。不能安全断行但原宽只略超限时，也可保留整体并小幅缩放。

分式参数、括号、矩阵及 `array` 不在内部拆分；一元负号不作为加减断点。可选参数、无括号大算子或由宏定义的运算作用范围无法明确时保守处理，不能据此承诺任意公式均可断行。闭合公式内部空行仅在排版副本中将段落 token 规范为空白；之后移除自动分行标记须与规范后的 token 完全一致，源参数保持原文。新增箭头与带注关系的边界见 [矩阵兼容说明](matrix-compat.md)。

安全方案与允许缩放仍放不下时停止，诊断含原文位置、公式宽度与实际可用宽度。不自动改成横向页，不无限缩小，不截断。带 `\tag` 或显式公式标签的公式继续走已有原生编号通道，当前不自动分行。

## 数学命令

前轮补齐 37 个标准命令（含 `\oint`），接续首批 101 个；后续再补 `\blacksquare` 和 `\xleftarrow`，清单见 [数学命令范围](math-commands.md)。新增命令均有原文往返和现有 XeLaTeX 编译检查。少数标准别名由模板定义为相同数学符号，源包保留原命令。

未知命令一次汇总；不自动加载笔记自定义宏或额外宏包。标准命令名称存在也不代表默认字体含全部字形，缺字仍明确报告。

## 六级标题

普通模式接受一至六级 ATX 标题，沿用首个正文标题提升规则，向下仍不可跳级。四至六级由受控样式生成独立题头，保留标签、链接和 PDF 书签；字体及间距区分层级，字号不低于正文。目录默认仍只显示到第二级。列表首行和续行中被原生解析器确认为标题的结构也保留。

## 有序列表与源题号

接受十进制、大小写字母、大小写罗马编号，以及原生支持的点号、右括号和双括号形式，例如 `1.`、`1)`、`(1)`、`a.`、`A)`、`(i)`、`I.`。遵循原生 Markdown 的空白规则，单个大写字母或罗马编号后建议使用两个空格。

列表最多四层，可以混合有序与无序。条目可有多个段落、公式、标题、代码块、已有支持的图表和单层普通引用，仍须正确缩进。长条目可以跨页，编号与起始内容保持同页，粗体独占题头与后段连排；公式按条目内剩余宽度排版。

默认 `--list-numbering auto` 接受连续编号及统一重复起始标记。例如从 `3.` 开始输出 `3、4…`，全部写成 `1.` 则自动递增。源编号有跳号、重复混用或前导零时，返回 `LIST_NUMBERING`，避免解析器静默改号。

确认这些数字是要保留的题号后，在 `check`、`export` 或 `batch` 上显式添加 `--list-numbering preserve`：

```powershell
.\.venv\Scripts\python.exe note2lecture.py check '.\private\note.md' --profile markdown --list-numbering preserve
.\.venv\Scripts\python.exe note2lecture.py export '.\private\note.md' --profile markdown --list-numbering preserve -o output/source-numbered-new
```

此选项逐项保留源标签，包括 `1、3、7`、前导零或重复题号；嵌套列表也按源标签显示。异常序列另发 `LIST_NUMBERING_PRESERVED` 警告。源标记及选择记录进 manifest；解析用的内部标记必须移除。该选项不用于 strict。
