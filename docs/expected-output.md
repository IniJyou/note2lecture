# N0.1 期望输出与核对清单

本文件保留 N0 确定的验收合同。N0 时没有实际 PDF 或 LaTeX；N1 的实际产物与通过项目见 [验收记录](n1-validation.md)，不能把合同本身当作实测结果。

## 1. 每篇文档的交付形态

以下是输出合同示意，`<任务名>` 由 N1 命令接口确定，不表示当前已有命令。三个样例各有独立输出目录，不做合并。

```text
output/<任务名>/
  lecture.pdf
  lecture-source/
    main.tex                 可直接编辑的正文与排版入口
    assets/                  实际被引用的 PNG/JPEG，按摘要命名
    template/                main.tex 实际依赖的本地样式/宏（若有）
    normalized.md            规范化工作副本，资源引用已重写
    render-config.yml        采用的受控配置，明确关闭模型与代码执行
    manifest.json            来源摘要、资源映射、工具/模板/字体版本
    README.md                离线重编译方法、依赖及限制
  diagnostics.json           诊断、源位置与检查状态
```

LaTeX 源包首先指完整目录，是否附加 ZIP 留 N1 决定。`.tex` 只有图片路径、样式文件和运行依赖齐全才算可重编译源包。临时编译文件、模型、缓存和运行日志不当作必需源包材料；失败日志独立保存并在诊断中给位置。

`manifest.json` 至少记录输入相对名称与 SHA256、输入协议版本 N0.1、实际配置、模板版本/摘要、资源原相对路径/包内路径/摘要、Python/Quarto/Pandoc/XeLaTeX 的实际版本和字体名称/可核验版本标识。没有采用的工具注明未使用；不得编造版本。只记录复现所需信息，不写私人绝对路径。

依赖字体和 TeX 软件不默认随包分发。源包 README 列明所需字体、TeX 包及是否已准备，缺依赖明确报错，不自动下载。重编译验收要求在已备齐依赖的情况下，**仅使用源包与 XeLaTeX，不调用原 Markdown、原图片目录、Quarto 或模型**。实际编译命令及所需轮数由 N1 实测后填写；不能先写未经验证的可运行承诺。

重编译后的内容、编号和引用应等价；不要求带时间元数据的 PDF 字节相同。允许编辑 `main.tex` 后重新编译；重新从 Markdown 导出使用新输出目录，不能覆盖用户编辑的源包。

## 2. 三篇正常样例的预期

各类环境独立计数，所有对象在单篇文档内编号。目录只包含外层一级、二级标题；环境内的 `##` 不进入目录。

| 样例 | 正常结构基线 | 固定内容锚点 |
| --- | --- | --- |
| `01-mean.md` | 2 个一级章节、1 个二级章节、1 个三级章节；两层列表；1 个代码块；1 条脚注；1 幅 PNG；1 个带标签公式 | 输入 2、4、9，总和 15，平均值 5，中位数 4；代码注释、异常字符串、`5.0` 均保留 |
| `02-projection.md` | 2 个一级章节；定义、引理、定理、例各 1 个；2 个证明；3 个独立公式，其中 2 个带标签 | `u≠0`、列向量形状、分母 `u^\top u`、非负平方项、等号条件完整；例中 9 与 10 不混淆 |
| `03-online-mean.md` | 3 个一级章节、2 个二级章节；1 个代码块；1 个五列表格（表头＋4 数据行）；1 幅 JPEG；2 个带标签公式 | 序列 2、4、8、10；表中 `无`、`14/3`、`16/3` 不改写；最终计数 4、均值 6；长字符串最后的 `count.` 保留 |

### 样例 01：基础阅读

| 标签 | 期望可见编号/引用 |
| --- | --- |
| `sec-mean`、`sec-steps`、`sec-check`、`sec-code` | 第 1 节、第 1.1 节、第 1.1.1 节、第 2 节 |
| `eq-mean` | 公式右侧 (1)，正文“式 (1)” |
| `fig-mean-flow` | 图 1，图题“先求总和，再除以数据个数” |

正文只出现一份标题、作者和日期。脚注首次引用显示上标 1，脚注正文完整。Python 缩进、中文注释、引号及空行保留，不产生执行结果。外链可点击，但转换不访问网页。图片完整显示三步流程，图题在图下。

### 样例 02：数学与前向引用

| 标签 | 期望可见编号/引用 |
| --- | --- |
| `sec-direction`、`sec-nearest` | 第 1 节、第 2 节 |
| `def-projection` | 定义 1（一维正交投影） |
| `lem-orthogonal` | 引理 1（残差与方向正交） |
| `thm-nearest` | 定理 1（直线上的唯一最近点） |
| `exm-two-dimensional` | 例 1（二维数值核对） |
| `eq-projection`、`eq-distance` | (1)、(2)，多行距离展开整体一个编号 |

开头对 `thm-nearest` 的前向引用指向定理 1。第一个证明内的独立公式不编号，不能让距离展开变为 (3)。两段证明各显示“证明”和一个结束方块，中文正文使用正体，不能因英文定理样式把整段中文斜体化。定理假设、等号条件与唯一性说明不得省去。

### 样例 03：长内容与资源

| 标签 | 期望可见编号/引用 |

资源路径中的中文与空格能够解析，包内采用摘要路径，无需原资源目录。表头与每格内容保持对应，不把“无”填为零。长字符串可在页面视觉折行，`.tex` 中代码内容不能被拆成改变语义的多行字符串；完整字符顺序与缩进可核对。

## 3. 共通内容核对

- 工作前后对输入与资源计算 SHA256，确认原文件未改；工作副本中允许的换行符规范化单独记录。
- 通过解析树列出正文块、代码块、数学块、标签、引用和资源清单；代码块与数学正文逐块核对，不能只统计块数。
- 检查章节、环境题头与图表题注没有重排成正文、漏掉或重复；允许环境题头的结构化呈现。
- PDF 中不得出现未解析的 `@thm-...`、`{#...}`、div 围栏或 `??`。正文代码字面量中的类似字符不作误报。
- 在源包独立副本内重编译，检查不存在指向原输入目录的依赖。检查内容、编号与引用，再逐页核对缺字、裁切、溢出、图题分离和异常分页。
- 程序完成、内容核对、页面检查、用户模板审美确认分别记录。生成 PDF 不等于数学内容或视觉验收通过。

## 4. N1 边界变体验收

下面是 N0 确定的最小验收动作，**N0 未执行转换测试**。N1 已执行的范围见验收记录。只修改临时副本，不改正常样例或私人原稿；变体不算新增公开笔记。

| 操作 | 期望 |
| --- | --- |
| 在样例 01 的公式前插入一个有标签独立公式 | 原 `eq-mean` 变为 (2)，图仍为图 1，其引用同步变化 |
| 交换样例 02 的两个外层章节 | 章节号随位置变化，标签含义不变，前向/后向引用均解析 |
| 复制样例 02 的定理并沿用标签 | `LABEL_DUPLICATE`，报告两处源位置，不报告完整成功 |
| 将一个引用改成 `@thm-not-found` | `REF_UNDEFINED`，定位该引用 |
| 移走副本中的 PNG；把 JPEG 副本改成非图片字节 | 分别 `RESOURCE_MISSING`、`RESOURCE_INVALID`，不替换占位后成功 |
| 把图片路径改为 `../outside.png`、绝对路径或远程 URL | `RESOURCE_PATH`，不读取或下载目标 |
| 从不同工作目录处理样例 03；重复引用同一张图 | 仍按入口目录找图；只打包一份相同资源，不改原文件 |
| 在副本下两个子目录放置同名、不同内容图片并引用 | 两份资源摘要不同，均完整保留，无覆盖 |
| 插入 `[[双链]]`、提示框或可执行 `{python}` 围栏 | `UNSUPPORTED_SYNTAX`，不执行代码 |
| 在普通代码块内放 `@thm-not-found`、`[[双链]]` 和美元符 | 作为字面内容保留，不误报引用或扩展错误 |
| 删除一个数学环境结束围栏；增加未知 YAML 字段 | 分别结构错误与元数据错误，指出起点或字段 |
| 在模板工作副本中缩短页面可用高度，使定理靠近页底 | 题头与首段同页，证明不丢内容，无巨幅留白；逐页检查并记录实际页码 |
| 在样例 03 副本中增加一条不能适配的超宽公式或表格 | 保留内容并报告 `LAYOUT_OVERFLOW`；不能靠截断或极小字号通过 |
| 把完整源包复制到项目外的新目录，再独立编译 | 依赖齐全时可重编译，无原资源、Quarto 或模型依赖 |

首套样张至少覆盖标题与目录、代码、数学环境与引用、长内容和分页边界；不预设页数。三篇短文自然分页未触发的边界，必须通过上述模板工作副本验证，不能据此直接宣称跨页行为通过。

输出链路依据：[Quarto PDF 文档](https://quarto.org/docs/output-formats/pdf-basics.html) 提供保留 `.tex` 的能力；完整源包、资源可移植性和重编译仍是本项目额外验收要求。
