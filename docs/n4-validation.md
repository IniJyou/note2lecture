# N4 首项批量导出验收

日期：2026-10-26。范围：明确选定文件的批量 PDF / LaTeX 导出，复用 N2 单篇链路。用户认可此首项范围并自行建立 `codex/n4-batch-export`；首轮仅使用原创公开样例，随后按用户指定完成五篇真实笔记试用。开发与验收阶段没有提交、推送、安装或下载；用户验收后分别授权本地提交、推送与合并，Git 收尾采用本地合并后推送 `main`。

## 实现与边界

- 新增 `batch` 命令：明确文件清单、共同的 `strict` / `markdown` / `obsidian` 模式和 Quarto 路径，按顺序逐篇处理，编号目录避免同名冲突。
- 根目录必须不存在；同一输入重复选择、目录和非法输入均有逐项诊断，不扫描整个笔记库。资源读取与单篇原有规则一致，不递归合并关联笔记。
- 每篇保留状态、检查项、完整诊断与相对产物路径；批次开始及每篇结束保存汇总。单篇失败继续其余项，任意失败最终退出 2；全部转换完成仍为 partial、退出 0，人工验收状态不自动升级。
- 意外单篇异常单独报告；诊断另存失败时仍在汇总中保留原因。中断尽可能保存已完成与待处理数量，退出 130，不提供自动续跑。

实际输入补充了七个常见数学命令（含小于/大于别名），列表项内的标题、代码、图片、基础表格、普通引用和空条目，以及圈号和代码星号字体。标题定位以解析树实际识别为准，仍校验跳级和原位置；strict 不扩展。超宽矩阵连等式在矩阵外层关系符处分行，矩阵行列与嵌套配对完整保留，删除生成布局标记后须与原 token 一致；未知或不配对环境仍保守报错。
