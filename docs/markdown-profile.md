# N2 普通 Markdown 适配

更新：2026-10-26。协议标记：`N2-markdown.1`。这是 N2 真实样本适配与 N4 选定笔记回归补充，尚不表示完成全部 Obsidian 扩展。

默认 `--profile strict` 继续使用 [N0.1 规范](input-spec.md)。只有显式指定 `--profile markdown` 才使用下列转换，不会改写原稿；确定性规则与生成标签写入源包 `manifest.json` 的 `adaptations`。

| 输入 | 转换规则 |
| --- | --- |
| 没有 YAML | 首个非空行若是 H1，取作书名并移出正文；其中的行内数学经过独立校验与受控渲染，封面/页眉保留数学，PDF 元数据使用源码纯文本表示；否则使用纯文本文件名。没有作者则不填写，不补日期 |
| 已有 YAML | 仍按 N0.1 校验四项白名单字段，不透传渲染配置；此时 title、author 仍必填 |
| 普通 ATX 标题 | 将正文起始层级提升到一级，其余相对层级保持，接受一至六级且向下不跳级；未显式标注的标题生成标签。四至六级保持独立题头、标签与 PDF 书签，目录默认到第二级。后端确认为列表首行或续行标题时，匹配其原位置；不把普通缩进文本强行升级为标题 |
| 手写章节编号 | 原样保留标题文字，关闭额外章节编号，包括目录；不猜测或修改编号含义 |
| 空 HTML 锚点 | 仅支持独占一行、双引号 id 的 `<a id="name"></a>`，含 NBSP 分隔也可；必须紧接下一标题，中间只能有空行 |
| `[说明](#锚点)` | 映射到同篇标题，保留说明文字与 PDF 跳转；不存在、歧义或重复锚点报错 |
| 章节号引用 `@sec-...` | 本模式不生成章节号，拒绝此写法；使用普通页内链接，或使用 strict 模式 |
| 独占段落的图片 | 必须有图题；缺标签时生成图标签，继续自动编号。图片格式、真实路径边界与字节校验同 N0.1 |
| 无表题的基础表格 | 保留表头、行列和单元格内容，不臆造表题或编号。接受行内代码；列宽等分，正文大小不变；跨页重复表头 |
| 相对本地文档链接 | 保留原说明和相对路径，显示“本地引用”，发出 `LOCAL_LINK_NOT_PACKAGED` 警告。不打开、不核验存在性、不递归合并或打包；原说明已等于路径时不重复显示路径 |
| 行内接口名与文件路径 | 正文中可在 `_`、`.`、`/` 后换行，不改变拼写；标题与 PDF 书签不作此替换 |
| 行内公式 | 接受 `$...$`、`\(...\)`，允许公式首尾空格及同一段内的软换行；保留公式正文的空格与换行，不能跨空行或新的 Markdown 块，未配对的分隔符仍报错 |
| 独立公式 | 接受独占行的 `$$` 围栏或 `\[` / `\]`；`$$` 也可紧贴跨行正文。支持既有列表、单层引用及段落内同行配对公式。已闭合的 `$$` 公式允许内部空白行，解析标记全部恢复，原公式保留；空、未闭合或跨标题/代码块仍报错，行内公式仍不能跨空段。跟在段落文字后的跨行公式须移到独立内容行。普通超宽公式优先按外层关系符、带说明箭头及明确的二元加减号分行，再考虑 1.12 倍边界内缩放；列表用容器实际行宽。无法安全排下仍报错，细则见 [矩阵与空白说明](matrix-compat.md) |
| 基础 `array` 数学环境 | 支持由 `l`、`c`、`r`、竖线和空白组成的列格式，例如 `{ccc\|c}`；保留增广矩阵的列、分隔线、行与原公式。不支持可选位置参数、宽度列、重复列或宏修饰；内部命令仍按数学白名单校验，环境必须正确配对 |
| 正文符号缺字 | 正文与正文标题中的 `①`、`②`、`③` 使用已有 Fandol 宋体，`∎` 使用 Latin Modern Math 显示原 Unicode 字形；保留粗体及书签。`★` 由已有 CJK 字体显示，代码中使用对应等宽字体。公式与代码原文字节不变，其他缺字仍报告 |
| 多段列表 | 条目内接受段落、公式、标题、代码、已支持的图表、单层普通引用和子列表，空条目保留，最多四层。接受十进制、大小写字母与罗马编号及原生支持的点号/括号格式。默认连续或统一重复标记自动编号，跳号/前导零等报 `LIST_NUMBERING`；显式 `--list-numbering preserve` 后逐项保留源题号并提示。条目起始预留空间，粗体独占题头与后段连排，长条目允许跨页 |
| 显式换行 | 保留 Markdown 的显式换行节点，普通段落软换行仍按原规则排版 |
| 手写公式编号 | 独立公式允许一个简单 `\tag{编号}`，编号由字母、数字、点、连字符或括号组成。保留原标记，不自动改为连续编号，也不为重复的手写数字生成关联标签 |
| 数学中的中文 | 使用同套 Fandol 中文字体显示，不将中文从公式中挪出或改写为其他命令 |
| 标题数学 | 正文与目录保留数学排版；PDF 书签用公式源码的纯文本表示，不显示内部占位符 |
| Markdown 分隔线 | 保留解析器识别的分隔线，不将其推断为章节或数学环境 |
| 正文顶层独占段落的 `[toc]` / `[TOC]` | 映射到模板已有目录，并记录适配；正文句子、代码和公式中的字面记号不作替换 |

数学仍只接受白名单。本模式增加 `\longrightarrow`、`\Longrightarrow`、`\mid`、`\odot`、`\dim`；长文回归补充 `\arcsin`、`\arccos`、`\arctan`、`\cot`、`\boxed`、`\bigl` / `\bigr`、`\Bigl` / `\Bigr`、`\uparrow`、`\downarrow`、`\therefore`、`\Longleftrightarrow`、`\square`、`\tag`、`\iiint`、`\oiint`。矩阵的 `\\x` 作为换行后接变量 x，不再误判成未知 `\x` 命令。连续反斜线之后的真正命令仍要校验，不允许 `\input` 等命令。

2026-10-26 真实批次补充 `\lt`、`\gt`、`\xrightarrow`、`\dagger`、`\checkmark`、`\arg`、`\bigcup`；前两个 MathJax 别名由模板定义为标准小于/大于关系符，源包仍保留原宏。默认 strict 白名单不扩展。

解析副本将行内公式作为数学原子读取，随后恢复原始正文；受控边界标记必须完整移除，不能把公式留作普通文字。行内与独立公式经后端后，在 `main.tex` 中恢复原文，防止首尾空格、软换行或列表缩进被后端改变；标题另提供受控书签文本。占位符数量、摘要及恢复后的原文均需核验。

根据用户于 2026-10-25 的最新阅读反馈，普通超宽公式不再单独使用横向页。程序保留完整原始参数，仅对 TeX token 副本插入换行：优先保留首个等式两侧在同一行，后续在外层 `=`、`<`、`>`、`\leq` / `\geq` / `\neq`（及短别名）处分行；外层 `\Longleftrightarrow`、`\Leftrightarrow`、`\Longrightarrow`、`\Rightarrow`、`\iff`、`\implies` 可开始续行。分式、命令参数及已配对括号内部不分行，不补推导或重排运算。删除生成的分行标记后，token 必须与原公式完全一致。

如果第一种布局仍宽，会尝试让首个外层关系符也开始续行，再尝试明确的外层二元加减号；按当前行宽合并相邻片段，优先保持字号。全部安全方案仍略宽时才在 1.12 倍边界内小幅缩放；没有可用断点但整体只略超限时允许整体缩放，仍放不下则报告原位置及实际尺寸。矩阵和受控 `array` 整块保留，只在环境之外选断点，不拆分行列或分隔线。成对裸竖线、已有 `aligned`、可选参数或大算子作用范围有歧义时，不猜测断点；仍可原样显示，超宽时按保守边界处理。日志中的 `N2LWRAPPED`、`N2LWRAPROWS`、`N2LWRAPDIMS` 记录分行摘要、行数及尺寸；不退回横向页或无限缩小字号。

带 `\tag` 或显式 `{#eq-...}` 的公式继续走原生编号通道，保持现有标签与交叉引用；当前不自动分行。手写编号不套测宽缩放盒，显式标签公式沿用原来的小幅缩放限制，超宽由编译诊断拦截。中间 Markdown / QMD 是生成工作副本，源包的独立编辑与重编译入口仍为 `main.tex`。

受控独立公式后，在同段内或块容器末尾紧接的短结语（可见长度不超过 80 个字符，行内公式按原子计）与公式连排，减少结语单独落到下一页。只调整分页约束，不合并文字、改写数学或强制一整节不分页；原生编号公式不增加此布局包装。

正文提取核对会忽略不可见的 U+200B 零宽空格，与布局空白、英文断词和兼容字形一同规范化；不会因此删除原稿或生成 TeX 中的原字符。

HTTP/HTTPS 外链保留但不抓取。本地引用警告不等同于缺失图片错误：前者明确作为文字交付，图片缺失、越界或损坏仍阻止导出。

本 markdown 模式对双链、Obsidian 图片嵌入和提示框仍给出诊断；这些基础扩展需显式选择 `--profile obsidian`，支持规则与样例检查见 [obsidian-fixture.md](obsidian-fixture.md)。Obsidian 块引用及其他 HTML 仍不支持。复杂表格、代码语言、数学环境等未列出的限制继续沿用 strict 校验，不承诺任意组合。
