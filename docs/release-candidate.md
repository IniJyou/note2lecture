## 隔离与验证范围

在同一台 Windows 电脑的全新项目副本创建独立 `.venv`，只安装 `requirements-gui.txt` 列明的运行依赖及必要传递依赖；不复制开发环境、缓存、Git 元数据或私人笔记。环境与安装获用户具体授权，未修改其他项目环境。

Quarto、TeX Live、字体、WebView2 和 .NET 复用已有系统工具；开发核对使用已有 Poppler。此范围不能表述为另一台干净电脑或全新系统安装验收。
