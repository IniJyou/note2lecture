- 结构核对：样例 01 为 2/1/1 个一级/二级/三级标题、两层列表、1 个代码块、1 条脚注、1 个独立公式；样例 02 为 4 个编号环境、2 个证明、3 个独立公式；样例 03 为 3/2 个一级/二级标题、1 个代码块、1 张表、2 个独立公式。与期望清单一致。
- 11 个 Markdown 文件均通过严格 UTF-8 解码，解析后的本地文档/图片链接均存在。两个代码块的 AST 正文与源块逐字对照一致（仅统一换行并去除围栏前的终止换行）；表格实测为 5 列、4 个数据行。代码未执行，这也不构成未来转换器的保真验收。
- 两幅图片引用均可解析；PNG 为 1200 × 320，JPEG 为 1200 × 360。已实际查看原图，数字与分批内容对应样例；这不代表 PDF 版面已经检查。
- Pandoc 对 `<assets/批次 示意.jpg>` 产生含 `%20` 的 AST 路径，资源规范已区分源写法与解析器规范化结果。其适配和可移植源包仍需 N1 实现。
- 本机 PATH 可找到 XeLaTeX，版本查询为 XeTeX **0.999996 / TeX Live 2024**；未在当前 PATH 发现 Quarto。这里只做工具发现，没有进行依赖完整性、字体或编译能力验收，也未锁定生产工具版本。
- 本轮为文档、样例和静态资源交付，没有 Python 转换代码，因此未运行 pytest、Ruff、模型评估或代码示例。没有实际 PDF、LaTeX 源包或端到端测试结果；用户尚未确认模板风格。
