# 数学书名、矩阵变换与公式空行

更新：2026-10-27。适用于 `--profile markdown` / `obsidian`，strict 的输入边界保持。本文补充 [常见兼容规则](common-compat.md)。

## 带说明的变换分行

普通独立公式增加外层箭头断点，包含 `\xrightarrow{说明}`、`\xleftarrow{说明}` 及已支持的常见单向箭头。矩阵、增广分隔线和箭头参数保持完整，沿用先分行后有限缩放的竖版策略。

对于 `\stackrel{说明}{关系符}`，仅在第二参数是明确的关系符（例如 `\simeq`、`=`、`\equiv`）且两个参数均显式分组时，才作为关系断点。说明中的运算符不作外层断点；未分组、额外空白或作用范围不明确时保守处理，不猜测数学含义。带可选下方标签的箭头仍沿用原生显示，当前不自动分行。

`\stackrel` 的说明若含顶层显式 `\\`，模板用原生 `\substack` 承载多行说明；单行说明沿用原实现。原调用及两个参数完整保留在 `main.tex`，排版时不增删条件或运算数。

## 证明结束符

增加 `\blacksquare`，模板在需要时用同符号的 `\mdlgblksquare` 提供标准别名。原宏保留，默认 Latin Modern Math 的字形经过原生编译与样张检查。`\xleftarrow` 同轮补齐，命令清单见 [数学命令范围](math-commands.md)。不安装字体或宏包。

## H1 书名中的行内数学

无 YAML 的笔记，首个非空 H1 仍作为书名并移出正文；其中的 `$…$` 或 `\(…\)` 现在可保留数学排版。先单独解析并校验受控行内内容和数学命令，再生成封面、页眉及 PDF 元数据；不直接把原始 LaTeX 指令写入渲染配置。

数学书名保留原数学内容的空格，纳入源包的受保护内容与摘要。封面和页眉显示数学；PDF 元数据与书签采用公式源码的纯文本表示，例如 `\lambda`，不残留内部标记。错误位置映射回原始 H1。

数学书名的受控通道仅支持文本、行内数学和基础行内样式，拒绝独立公式、链接、原始 HTML/TeX 指令或文件/执行命令。YAML 显式书名与文件名回退规则仍沿用原有纯文本约定；strict 不扩展。

## 闭合独立公式中的空行

配对的 `$$` 独立公式内部可以有空白行，包括列表或普通引用中的公式。解析副本在这些位置插入受控标记，原生解析为完整数学节点后全部移除，恢复公式空格与换行；原稿及原行号不变。

最终 TeX 的完整公式参数继续保留原文。仅在排版副本中将空行产生的 `\par` token 递归规范为空白，包含分子等参数内部，不展开数学命令、不改变分组。完成这一步后，移除自动分行标记仍须与规范后的 token 完全一致。带手写编号的公式保持原生编号，空白处理不改号。

空公式、未闭合分隔符、越过新标题或代码块仍报错；行内公式仍不能跨空段。首版不把这些规则泛化到任意数学分隔符或文档结构。
